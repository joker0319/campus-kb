# 参考站与设计决策溯源

记录用户提供的一手设计参考，以及每个参考在本项目里的取舍结论。目的是让后续维护者理解「为什么这样设计」，避免反复推翻。

## 用户提供的参考

用户在项目早期给出的审美锚点与参考：

1. 六.UI 设计站链接（用于"提高审美"）
2. 一份 **bento 五宫格像素级复刻 prompt**（约 8000 字，含度量系统）

后续明确要求遵循的设计语言来源：

> motionsites、aceternity、showreel、uiverse、reactbits、animejs

## 六个站点的定位与取舍

| 站点 | 类型 | 核心特征 | 本项目取舍 |
|---|---|---|---|
| **motionsites** | 动效站点案例库 | 一次性入场编排、滚动叙事、节奏时间表 | 取 staggered 时间表演示法；落地为 `--d` 独立延时 |
| **aceternity** | React 组件库 | aurora / spotlight / bento / 卡片hover 光斑 | 取 aurora + 渐隐网格 + ring 描边；**拒绝**过量光斑 |
| **showreel** | 作品集/展示站 | 编辑感排版、超大衬线标题、字距收紧 | 取衬线大标题与留白，落地为主标题 clamp 2.9~4.6rem |
| **uiverse** | 微交互组件库 | 有生命感的小组件、呼吸/跟随/弹性 | 取微动理念，落地为墨点精灵（呼吸/眨眼/瞳孔跟随） |
| **reactbits** | React 动效片段库 | 纯 CSS 3D、粒子、文本动效 | 取 3D 卡堆，落地为 CaseStage（不用 three.js） |
| **animejs** | 动画引擎 | 缓动曲线、编排 API、镜像时序 | 取缓动统一与时间表思维；不引入库本身 |

## bento 五宫格 prompt 的决策

**原始内容**：度量基准 1374×666，五张卡片的精确坐标、渐变、SVG 与入场时间表。用于生成第一版首页原型 `prototype/v1-mosaic.html`。

**用户反馈链条**：
- 初见提示词：采用，做出第一版 mosaic 原型
- 看到效果后："ai 味有点重" → 反复要求删减文案、精简卡片
- 最终："九件规范一套写法也去掉"、"展现出一个首页该有的东西" → bento 方案废弃

**保留 / 废弃对照**：

| 保留 ✅ | 废弃 ❌ |
|---|---|
| 先定基准画布与坐标再写 CSS 的度量思维 | 五宫格密集卡片堆叠 |
| 一次性入场 + 独立延时编排 | 逐字动画配氛围文案 |
| 时间表驱动的开发方式 | 紫粉渐变/玻璃拟态堆叠 |
| 缓动统一原则 | 为炫技而生的循环动画 |

**结论**：这份 prompt 是"度量方法"的教科书，但不是"视觉风格"的模板。项目最终走的是**纸墨感 + 数据驱动 + 分层克制**的路线。

## 关键设计决策时间线

| 阶段 | 决策 | 触发 |
|---|---|---|
| 第一版 | bento 五宫格 + 全套动效 | 用户给的复刻 prompt 与六个站 |
| 去 AI 味 | 删氛围文案、简化卡片、改纸墨配色 | 用户"ai味有点重" |
| 交互化 | 加 3D 卡堆、放大轮播 | 用户"想不加些3d的东西 或者是轮播图" |
| 宠物化 | 墨点换成会动的小精灵 | 用户"换成小宠物那种 点一下能动动的" |
| 助手入口 | 墨点改为进入助手、文案改"知识库的个人助手" | 用户"那个小黑色动画我希望他是个进入agent助手的部分" |
| 结构回归 | 首页恢复导航/主体/底部，删校验罗列 | 用户"展现出一个首页该有的东西" |
| 轮播归位 | 3D 卡堆放回 hero 右栏 | 用户"把之前的轮播图还放在原来的位置" |

**给维护者的提醒**：以上每一条都是用户明确表达的偏好，不是随意选择。改动前先判断会否违背其中任何一条——尤其是"去 AI 味"和"分层克制"两条主线。
